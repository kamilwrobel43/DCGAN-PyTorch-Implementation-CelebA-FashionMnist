# 🎨 Generative Adversarial Networks (GANs): Classic and Deep Convolutional (DCGAN) Implementation

A repository exploring the implementation of Generative Adversarial Networks (GANs) and Deep Convolutional GAN (DCGAN) [Generative Adversarial Nets](https://arxiv.org/abs/1406.2661), [UNSUPERVISED REPRESENTATION LEARNING
WITH DEEP CONVOLUTIONAL
GENERATIVE ADVERSARIAL NETWORKS ](https://arxiv.org/abs/1511.06434)

---

## ✨ Key Features & Scope

* **Architecture Implementation:** Includes complete implementations for both the foundational **Classic GAN** and the powerful **DCGAN** model.
* **DCGAN Focus:** The project primarily benchmarks and presents results using the **DCGAN** architecture.
* **Dual Dataset Testing:** Models were rigorously tested and evaluated on two distinct image datasets:
    * **Fashion-MNIST:** A dataset of clothing and accessory images.
    * **CelebA (Large-Scale CelebFaces Attributes):** A dataset featuring celebrity faces, used for more complex image generation tasks.
* **Training Visualizations:** Provides dynamic **GIFs** showcasing the evolution of generated samples across training epochs for a **fixed latent noise vector**, alongside corresponding training loss plots.
